# Workforce Attrition Patterns and Risk Hotspot Analysis

## Files
- `app.py` — Streamlit dashboard
- `Palo Alto Networks(4).csv` — dataset
- `requirements.txt` — required Python libraries
- `PROJECT_REPORT.md` — project report and findings

## How to run
1. Install Python.
2. Open Command Prompt/Terminal in this folder.
3. Run:
   `pip install -r requirements.txt`
4. Start the dashboard:
   `streamlit run app.py`

The dashboard will open in your browser.

## Dashboard modules
1. Attrition Overview
2. Department & Role Risk Hotspots
3. Demographic Attrition Explorer
4. Tenure & Workload Analysis
5. Key Findings and HR recommendations

## Note
The analysis is descriptive/diagnostic. It does not establish causal relationships.
